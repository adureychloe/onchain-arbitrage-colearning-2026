# 链上套利残酷共学

这是 [Intensive Co-learning 链上套利课程](https://intensivecolearn.ing/programs/b43d2e97-ed88-4ca3-b12f-7ef672b01205) 的公开学习记录仓库。共学周期为 **2026-08-05 至 2026-08-26**，按天记录研究、实验、模拟和复盘过程。

## 项目目标

- 建立可复用的链上套利研究工作流，而不是追逐单次收益。
- 记录每一天的目标、证据、假设、成本和失败原因，便于复盘与同行检查。
- 将机会发现、路径验证、策略建模和风险边界拆开，严格区分研究、模拟、纸面交易和真实执行。
- 形成可公开讨论、可逐步复现且不暴露敏感信息的学习档案。

## 状态定义

每条记录必须标注当前状态，避免把推测误写成执行结果：

- **研究**：正在收集资料、提出问题或检查数据，尚未验证策略可行性。
- **模拟**：使用历史数据、测试网或本地环境验证逻辑，不发送真实交易。
- **纸面交易**：按明确的时间、价格和成本假设记录虚拟订单，结果不代表可实现收益。
- **真实执行**：在真实网络提交了交易或跨链操作；必须记录风险、授权范围和可核验的交易链接。

## 公开边界与风险声明

本仓库仅用于个人学习和过程记录，**不构成投资建议、交易建议或任何收益承诺**。链上交易存在价格波动、智能合约漏洞、桥和路由失败、流动性不足、抢跑、网络拥堵及资产损失等风险。任何示例都不代表未来结果，也不应作为他人交易依据。

公开仓库绝不提交私钥、助记词、钱包导出文件、API 密钥、访问令牌或其他凭据。真实账户地址、订单细节和原始数据在公开前应先脱敏；本地凭据和实验原始数据由 `.gitignore` 排除。发现疑似泄露时，应立即撤销/轮换凭据并停止传播相关提交。

## 记录约定

每篇每日记录至少说明：今日目标、完成内容、证据链接、观察与假设、成本拆解、当前状态、失败原因和明日行动。数据来源、时间戳、链与资产单位应写清楚；没有收益也应如实记录，优先保留可复核的过程证据。
