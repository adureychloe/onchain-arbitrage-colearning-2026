# 阶段五：捕获、实施与复盘

## 阶段目标

建立信号出现时的真实性、可执行性和风险检查，记录收益与失败，识别可重复机会和偶然噪声，形成下一阶段研究方向。

## 关键问题

- 信号出现后，哪些检查必须先完成？
- 研究、模拟、纸面交易和真实执行的边界如何保持清晰？
- 哪些结果可重复，哪些结果只在特定区块或流动性状态下成立？

## 阶段证据

- [Day-18 信号检查清单](../days/day-18.md)：三层门（真实性 → 可执行性 → 风险）+ 四种状态边界，附今日 `spread=0.002% exit 0` 实测。真实只读报价 `experiments/raw/spread-day18.json`。
- [Day-19 捕获或放弃](../days/day-19.md)：一次「放弃」决策的完整证据链 + 三次采样对照（蓝筹价差常态 ~0.01%）。
- [Day-20 执行与风险复盘](../days/day-20.md)：20 天失败模式/成本误差/风险边界汇总，区分可重复结论与噪声。

## 当前结论

- 最小检查顺序 = **真实性 → 可执行性 → 风险**，顺序即价值：真实性最便宜且拦最多假信号，可执行性花一次 quote，风险是资本投入前最后一道闸。
- 信号默认动作是「记录 + 只读验证」；四种状态（研究/模拟/纸面交易/真实执行）只能逐级推进，不能跳级。
- 三次独立采样（day-13/18/19）价差稳定在 `0.002%~0.012%`，**蓝筹跨链价差常态 ~0.01%**，比成本底价 `0.26%` 低一个数量级——蓝筹跨链价差套利无执行机会，是可复用结论。
- 复盘区分「可重复结论」与「噪声」：可重复的来自独立采样一致性（价差常态/成本底价/波动分布），噪声来自单次快照（单次 tool 选择、单次价差值）。
