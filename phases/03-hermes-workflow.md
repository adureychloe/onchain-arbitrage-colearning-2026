# 阶段三：用 Hermes 构建研究与信号工作流

## 阶段目标

把一次性的观察拆成可重复查询、数据整理、告警或 Agent 工作流，并为候选机会保留完整证据。

## 关键问题

- 研究问题如何拆成稳定的输入、工具调用和输出？
- 哪些字段必须长期记录：时间、链、资产、规模、路径、成本和失败原因？
- 如何区分工具输出、自己的判断和需要人工复核的结论？
