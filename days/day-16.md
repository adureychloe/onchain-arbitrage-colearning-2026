| 资产 | ETH，Arbitrum `$1895` → Base 假设 `$1910`（0.8% 溢价） |
| 规模 | `1 ETH` |
| 路径 | Arbitrum → Base 跨链（`across` 桥，day-14 实测） |
| 成本 | 协议费 `$4.74` + 桥费 `$0.20` + Gas `$0.016` = **`$4.95`（≈0.26%）** |
| 表面毛利 | `0.8% × $1895 = $15.16` |
| 扣除成本净收益 | `$15.16 − $4.95 = +$10.21（≈0.54%）` |

**判定：记录，但不执行。**

理由：跨链非原子——`across` 桥到账约 1–10 分钟，而 `0.8%` 的价差窗口通常只有秒级；资产到账时价差大概率已收敛，净收益由正转负的概率高。表面 `+$10.21` 是「静态快照的幻觉」，与 day-13 的「Quote 盈利 ≠ 到账时机会还在」结论一致。

## 信号出现后不执行的明确条件（失败条件清单）

### A. 执行前否决（信号触发，但下单前否决）

1. **可成交验证失败**：`/v1/quote` 的 `toAmountMin` 真实价差 < 成本底价 `0.26%`，即使 CoinGecko 价差触发阈值也不执行。
2. **跨链非原子**：桥到账时间（1–10 min）> 价差存续窗口（秒级）→ 不临时跨链，改用「两端预置资金」模式。
3. **滑点超限**：`toAmount` 与 `toAmountMin` 差距 > 请求的 `0.5%`，说明池子深度不足。
4. **流动性不足**：目标链池子太浅，规模稍大即产生非线性滑点。

### B. 策略级停止（跨笔累计判断）

5. **累计亏损停止**：纸面交易累计净收益 < 0，停止该策略（呼应 day-13 停止条件）。
6. **资金占用超限**：单笔规模超过预置资金合理比例，拒绝扩大敞口。
