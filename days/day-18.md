## 信号检查清单（三层门）

### 第 0 步：信号筛查（触发）

`experiments/lifi_price_spread_watch.py` 输出机器可读 JSON + 退出码：

| 退出码 | 含义 | 下一步 |
| ---: | --- | --- |
| `0` | 未触发（正常） | 记录，结束 |
| `1` | 触发阈值 | 进入第 1 层检查 |
| `3` | symbol 不匹配 | 直接拒绝（token 地址需人工核对） |

**今日实测**：`2026-08-22T13:45Z ETH: chain 8453=$2423.67 chain 42161=$2423.61 spread=0.002% → exit 0`，未触发，与 day-17「蓝筹跨链价差常态极小」的结论一致。原始输出：`experiments/raw/spread-day18.json`。

### 第 1 层：真实性检查（数据是否为真）

信号只是 CoinGecko 估值，进入执行前先确认它不是数据假象：

1. **同资产校验**：两链 `symbol` 是否一致。USDC 与 USDC.e 是不同资产，直接拒绝（脚本 exit 3 已处理，但仍需人工复核 token 地址）。
2. **价格口径**：`priceUSD` 是 CoinGecko 估值，**不是可成交价**。触发只代表「值得用 quote 再查一次」，不构成任何执行依据。
3. **采样时间戳**：`queried_at_utc` 是否存在。没有时间戳的价差无法区分「市场变化」与「报价过期」。
4. **校验状态**：`verificationStatus` 是否 `verified`；未验证资产的价差可信度低。

> 本层成本：一次数据校验，零资金暴露。失败（假信号）就在这里终止，不进入 quote。

### 第 2 层：可执行性检查（能否按价成交）

本层用 `/v1/quote` 的真实可成交价验证，取代估值：

1. **可成交验证**：`toAmountMin`（滑点调整后）的真实价差 ≥ 成本底价 `0.26%`。CoinGecko 价差再大，quote 不达标也不执行。
2. **跨链非原子否决**：桥到账时间（1–10 min）> 价差窗口（秒级）→ 不临时跨链，仅允许「两端预置资金」模式。
3. **滑点超限**：`toAmount` 与 `toAmountMin` 差距 > 请求的 `0.5%`，说明池子深度不足。
4. **流动性不足**：目标链池子太浅，规模稍大即产生非线性滑点。

> 本层成本：一次 quote 调用 + 一次成本比对。任何一项不达标 → 否决，进入「纸面记录」而非执行。

### 第 3 层：风险检查（失败与停止条件）

前两层通过后，最后一层判断「这笔/这个策略还能不能继续」：

- **执行前否决（单笔）**：第 2 层任一失败、授权范围不明确、合约地址未独立核验 → 否决。
- **策略级停止（累计）**：纸面累计净收益 < 0；单笔规模超资金占用上限 → 停止该策略。

> 本层是资本/时间投入前的最后一道闸。真实执行前还必须独立核验合约地址、审计历史、暂停/升级权限与可承受损失（安全边界，见 README 公开边界）。

## 四种状态的边界

| 状态 | 定义 | 进入门槛 |
| --- | --- | --- |
| **研究** | 只读 API 报价、收集资料、检查数据 | 默认状态；任何信号先落在这一层 |
| **模拟** | 历史数据 / 测试网 / 本地环境验证逻辑，不发送真实交易 | 第 1、2 层在纸面上通过 |
| **纸面交易** | 按明确时间、价格、成本假设记录虚拟订单 | 有明确进出场计划 + 完整成本拆解 |
| **真实执行** | 真实网络提交交易或跨链操作 | 独立合约核验 + 用户显式授权 + 可核验交易链接 |

**升级规则**：只能逐级推进，不能跳级。信号默认动作是「研究 + 只读验证」；每一次升级都必须有对应层的检查证据支撑。
