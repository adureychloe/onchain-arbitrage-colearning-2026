# Day-03｜2026-08-07｜从价差到净收益

> 阶段：阶段一：建立链上套利地图<br>
> 今日问题：屏幕上的价差扣除 Gas、手续费、滑点和延迟后还剩多少？

使用模板：[`daily-note.md`](../templates/daily-note.md)

## 今日目标

- 为一个候选价差写出最小成本拆解。

## 学习记录

评估屏幕上的套利或跨市场价差到底能保留多少，关键在于把**隐形成本**逐项扣除。许多“看起来很美”的价差，在扣除硬性成本和市场摩擦后，净收益往往会严重缩水甚至由盈转亏。

为了清晰拆解，我们假设屏幕上观察到某对资产/交易对的**理论表面价差为 $\Delta P_{gross}$**。

### 净价差公式 (Net Spread)

$$\Delta P_{net} = \Delta P_{gross} - (C_{gas} + C_{fee} + C_{slippage} + C_{latency})$$

只有当 $\Delta P_{net} > 0$ 时，该套利/交易策略才具备真实可执行的微观盈利空间。

### 候选价差的最小成本拆解 (Cost Breakdown)

针对一次标准的跨链、跨 DEX/CEX 或跨池套利候选交易，最小成本可拆解为以下四大类：

#### 1. Gas 费成本 ($C_{gas}$)

链上交互所需的硬性资源开销（如果是 CEX 间交易，则对应提币/充值跨链手续费）。

- **计算公式：** $C_{gas} = \text{Gas Used} \times \text{Gas Price} \times \text{Native Token Price}$
- **拆解项：**
  - **买入端交易 Gas**（如 Uniswap Swap）
  - **卖出端交易 Gas**（如 Sushiswap Swap 或跨链 Bridge 授权）
  - **优先费 / 小费**（如 MEV-Boost / Flashbots 竞价小费，用于保证打包优先级）

#### 2. 手续费成本 ($C_{fee}$)

交易平台或协议收取的定额/按比例佣金。

- **拆解项：**
  - **买入端协议手续费**（如 DEX 固定的 $0.05\% \sim 0.3\%$ 流动性费率，或 CEX 现货 Taker 费率）
  - **卖出端协议手续费**
  - **跨链桥协议费**（若涉及跨链套利，通常含固定的 Bridge Fee 或 $0.05\% - 0.1\%$ 桥接费）

#### 3. 滑点成本 ($C_{slippage}$)

因为你的交易量注入流动性池而引起的吃单价格劣化（价格冲击）。

- **计算公式（恒定乘积 AMM 简化估算）：** $\text{Slippage} \approx \frac{\text{Trade Amount}}{2 \times \text{Pool Liquidity}}$
- **拆解项：**
  - **买入端价格冲击（Price Impact）**：买入大单拉高价格造成的额外成本。
  - **卖出端价格冲击（Price Impact）**：卖出大单砸低价格造成的额外成本。

#### 4. 延迟与下行风险成本 ($C_{latency}$)

从“看到屏幕价差”到“交易最终上链/匹配”的时间差内，市场价格变动或被抢跑带来的损失。

- **拆解项：**
  - **逆向选择损失（Adverse Selection）**：在订单等待确认时，目标池价格被其他流动性提供者或套利者先一步吃掉（被抢跑 / Sandwich 攻击）。
  - **未成交损耗（Revert Cost）**：若因延迟导致条件不满足交易 Fail/Revert，已消耗的 Gas 依然无法退回的风险成本估算（即 $\text{Fail Rate} \times \text{Average Revert Gas}$）。

### 最小成本拆解清单（示例计算）

假设你在链上观察到 **1 ETH** 在 DEX-A 与 DEX-B 之间存在 **$15** 的理论价差：

| **成本分类**          | **拆解明细项**                    | **单项估算成本 (USD)** | **累计扣除** |
| --------------------- | --------------------------------- | ---------------------- | ------------ |
| **理论表面价差**      | $\Delta P_{gross}$                | **+$15.00**            | **+$15.00**  |
| **1. Gas 费**         | 买卖双边 Swap Gas + Flashbots Tip | -$3.50                 | +$11.50      |
| **2. 手续费**         | 双边 DEX 0.3% 流动性池手续费      | -$4.00                 | +$7.50       |
| **3. 滑点**           | 买卖双边 Pool Price Impact        | -$2.00                 | +$5.50       |
| **4. 延迟与概率损耗** | 考虑到 10% 的失败/抢跑率衰减折算  | -$1.50                 | **+$4.00**   |

**最终评估结论：** 屏幕上的 **$15** 表面价差，在扣除全部硬性与概率成本后，**实际剩余净利润约为 $4.00**。如果净额为负或过小（低于风险偏好阈值），该候选价差应被自动过滤弃用。
