## 成本误差分析

| 成本项 | 估计误差 | 依据 |
| --- | --- | --- |
| 协议费 / 桥费 / Gas | **低** | 跨链 quote 精确归因，到账损失与明细合计吻合 |
| 滑点 | **高** | 随规模/池深非线性，仅有 0.5% 请求上限 |
| 失败率（失败交易期望） | **高** | 无实测 |
| 资金占用利率 | **高** | 无实测 |

**核心误差结论**：成本底价 `0.26%` 的下界可信（费用可精确归因），但上界被「失败率 + 资金占用」两项未实测项拉高——真实成本底价只可能 ≥ `0.26%`，这进一步坐实蓝筹套利 Edge 为负。

## 可重复 vs 噪声（今日问题核心）

**可重复（结构性结论，独立采样下成立）：**

| 结论 | 证据强度 |
| --- | --- |
| 蓝筹跨链价差常态 ~`0.01%` | 三次独立采样一致（0.002%~0.012%） |
| 跨链成本底价 `0.26%` | quote 精确归因，低误差 |
| ETH 5 分钟波动中位 ~`0.14%` | 单日 289 点样本，量级可信 |
| 费用已含在数量流，不可重复扣减 | day-08 + day-14 两次验证 |

**噪声（特定区块/流动性状态，不可外推）：**

- 单次 quote 的 tool 选择（Nordstern / kyberswap / fly / across 每次不同）
- 单次价差的具体数值（`0.002%` vs `0.012%` 的差异无意义）
- `executionDuration=0`（无区分力的字段，不是真实耗时）
