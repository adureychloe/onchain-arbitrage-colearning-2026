# 链上套利残酷共学学习仓库设计

## 背景

本仓库用于记录「链上套利残酷共学」21 天的公开学习过程。共学时间为 2026-08-05 至 2026-08-26，主线包括套利机会地图、LI.FI 路径发现、Hermes 研究工作流、策略假设与成本模型，以及捕获与复盘。

仓库的目标不是提供收益承诺或交易建议，而是让每一天的学习目标、证据、假设、实验、失败原因和下一步行动都可以被回看、复现和讨论。

## 目标与非目标

### 目标

- 以 `day-01` 至 `day-21` 固定编号记录每日学习进度。
- 按五个主题阶段组织内容，便于从每日记录回到研究结论。
- 将研究、模拟、纸面交易和真实执行明确分开。
- 为实验、周复盘和最终总结提供可复用模板。
- 通过 GitHub Issue 模板和自动检查降低维护成本。

### 非目标

- 不自动执行真实交易，不托管私钥、助记词、API 密钥或账户身份信息。
- 不在第一版建立复杂的数据库、静态站点或自动化知识图谱。
- 不把未验证的价格差或收益数字包装成可复制策略。

## 内容模型

### 每日记录

每篇每日记录使用相同结构：

1. 今日目标与对应阶段。
2. 完成内容和证据链接。
3. 观察、待验证假设与反例。
4. 成本拆解：Gas、协议费、桥费、滑点、延迟和资金占用。
5. 状态标记：研究、模拟、纸面交易或真实执行。
6. 结果、失败原因和可信度。
7. 明日唯一最重要行动。

记录只写可验证的事实和明确标注的推测。若没有可执行机会，也记录“未执行”的原因。

### 阶段页

每个阶段页列出该阶段要回答的问题、相关每日记录、关键证据、当前结论和未决问题。阶段页是聚合视图，不重复复制每日笔记的全部内容。

### 实验记录

实验记录描述输入、步骤、代码或查询、输出、限制和复现方式。真实交易只允许以脱敏后的结果和链接出现；默认使用模拟或纸面交易。

### 复盘

每 7 天写一篇周复盘，最后写一篇最终总结。复盘聚焦假设变化、证据质量、时间投入、失败模式和下一阶段行动，不以收益作为唯一指标。

## 进度与链接策略

- 每日文件使用固定编号，文件名不随日期或标题改变。
- README 维护 21 天清单和阶段进度。
- 阶段页链接到每日记录，实验链接回对应日期，复盘链接回阶段页和实验。
- 链接使用仓库内相对路径，便于 GitHub 和本地阅读。

## 安全与公开边界

- `.gitignore` 忽略 `.env`、密钥文件、钱包导出文件、原始个人数据和本地缓存。
- GitHub Actions 运行 Markdown 链接检查和基础敏感信息扫描。
- 不公开私钥、助记词、API 密钥、精确账户标识或未经授权的个人数据。
- 研究、模拟、纸面交易、真实执行四种状态必须在文档中明确标注。
- README 固定声明：本仓库是学习记录，不构成投资建议或收益承诺。

## 验证方式

- 初始化后检查目录和 21 个每日文件是否齐全。
- 检查所有内部 Markdown 链接指向存在的文件。
- 检查模板字段在每日记录中保持一致。
- 推送前运行本地 Markdown 链接检查；推送后由 GitHub Actions 再验证。

## 后续扩展

当 21 天记录产生稳定的数据结构后，再考虑增加 CSV/SQLite 指标、自动生成进度图表或研究仪表盘。第一版保持 Markdown 优先，确保记录阻力最低。
