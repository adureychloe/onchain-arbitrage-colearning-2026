# 实验记录

实验用于回答一个可验证的问题。每个实验单独建文件，使用 [`templates/experiment.md`](../templates/experiment.md) 的字段，并从对应的每日记录链接回来。

## 最小记录要求

- 问题、假设和状态（研究/模拟/纸面交易/真实执行）。
- 输入、数据来源、查询或代码、执行时间和环境。
- 输出、成本拆解、失败原因、限制和结论。
- 可复现步骤；真实执行结果必须脱敏。

## 安全边界

默认使用公开数据、模拟或纸面交易。原始大文件放在 `experiments/raw/`，不要提交凭据、账户身份、私钥、助记词或 API 密钥。任何真实执行都必须先独立核验权限、安全、成本和可承受损失。
